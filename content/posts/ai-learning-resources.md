| 资源 | 链接 | 平台 | 费用 |
|------|------|------|------|

| 《Designing Machine Learning Systems》（Chip Huyen） | [作者主页](https://huyenchip.com) | O'Reilly | 付费 |

### DeepLearning.AI 推荐短课

- **LangChain for LLM Application Development** — LangChain 应用开发
- **Building and Evaluating Advanced RAG Applications** — 高级 RAG 构建与评估
- **AI Agents in LangGraph** — 使用 LangGraph 构建 AI Agent
- **Multi AI Agent Systems with CrewAI** — 多 Agent 系统

> 以上课程均可在 [deeplearning.ai/short-courses](https://www.deeplearning.ai/short-courses/) 找到

## 推荐学习路径

1. **概念层**：AI for Everyone → 建立全局认知
2. **实践层**：DeepLearning.AI 短课 → 学习 LangChain、RAG、Agent
3. **工程化**：《AI Engineering》（Chip Huyen）→ 系统化理解 LLM 应用
4. **动手做**：选一个框架（LangChain / Dify / Coze）→ 做一个真实项目
